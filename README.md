# gemini-canvas-mission

Gemini Canvas 미션 결과물을 관리하는 저장소입니다.

## 목적

- Gemini Canvas로 제작한 웹앱 결과물을 기록하고 공유합니다.
- 앱별 요구사항, 배포 링크, 회고를 일관된 형식으로 남깁니다.

---

## 앱 이름: AI 영양 성분 분석기

## 카테고리: 유틸리티 앱

### 배포 링크

[https://gemini.google.com/share/95409f572741](https://gemini.google.com/share/95409f572741/)

### 이 앱을 만든 이유

- 어떤 문제/불편함을 해결하려고 했나요?
    - 다이어트 혹은 운동을 하면서 먹은 음식의 칼로리나, 단백질 함량을 알기 어렵다는 불편함을 해결하려했습니다.
- 이 앱을 언제, 어떻게 사용할 건가요?
    - 식사를 하기 전에 사진을 찍어서 단백질 함량은 얼마나 되는지 칼로리는 얼마나 되는지 파악하기 위해 사용할 생각입니다.

### 주요 기능

- 실시간 카메라 촬영 기능
- 갤러리 사진 업로드 기능
- AI 기반 음식 사진 분석
- 분석 내용을 바탕으로 음식 이름,  예상되는 칼로리, 단백질, 지방 함량을 출력

### AI 기능

- 어떤 AI 기능을 추가했나요?
    - 촬영되거나 업로드 된 사진을 바탕으로 AI가 음식을 인식하여 예상되는 칼로리, 단백질, 지방 함량을 출력합니다.
- AI 기능이 앱에서 어떤 역할을 하나요?
    - 음식을 인식하고 예상되는 칼로리, 단백질, 지방 함량을 출력합니다.
    - 음식에 대한 설명을 출력합니다.

## 앱 이름: 행성이의 은하계 건너기

## 카테고리: 게임

### 배포 링크

[https://gemini.google.com/share/4fd6517ad360](https://gemini.google.com/share/4fd6517ad360/)

### 이 앱을 만든 이유

- 행성이 캐릭터로 게임을 만들어보면 좋겠다고 생각해서 행성이 이미지로 게임을 만들었습니다.
- 예전에 즐겨했던 ‘길 건너 친구들’이라는 게임을 참고해서 단순하고 쉽게 플레이 가능한 게임을 만들었습니다.

### 주요 기능

- 키보드 화살표와 플레이 화면의 방향 키패드 터치로 조작 가능
- 앞으로 움직일 때만 점수 추가 기능
- 최종 점수 표시 기능
- 현재 최고 점수 표시 기능
- 무지개 색의 소행성과 충돌할 경우 3초 간의 충돌 무시 기능

## 앱 이름: 자바 Stream 시각화 학습 시뮬레이터

## 카테고리: 학습 앱

### 배포 링크

[https://gemini.google.com/share/8b7722fb15ac](https://gemini.google.com/share/8b7722fb15ac)

### 이 앱을 만든 이유

- 어떤 문제/불편함을 해결하려고 했나요?
  - 부족한 Stream 공부를 어떻게 하면 좋을지 고민이 많았는데 이러한 고민을 해결하기 위해 만들었습니다.
  - Stream을 공부하면서 어떤 식으로 동작되는지 직관적으로 알기 어려울 때가 있었는데 시각화를 통해 이해하는데에 도움이 될 수 있도록 구성했습니다.
- 이 앱을 언제, 어떻게 사용할 건가요?
  - Stream 공부를 할 때 개념 공부와 더불어 실습하기 위해 사용할 계획입니다.

### 주요 기능

- Stream의 동작 흐름을 확인할 수 있는 시각화 된 개념 학습 자료 출력
- 학습한 Stream을 객관식, 단답형, 서술형 문제 풀이 기능
- 문제 풀이가 완료되지 않았을 때, 정답 확인, 다음 문제 버튼 클릭 시 재확인 기능

### AI 기능

- 어떤 AI 기능을 추가했나요?
  - AI를 활용해 Stream 문제를 생성하도록 했습니다.
- AI 기능이 앱에서 어떤 역할을 하나요?
  - 실습 모드 진행 시 개념 학습 탭의 5가지 주제들을 바탕으로 랜덤하게 객관식, 단답형, 서술형 문제를 생성합니다.
