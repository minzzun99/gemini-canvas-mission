# gemini-canvas-mission

Gemini Canvas 미션 결과물을 관리하는 저장소입니다.

## 목적

- Gemini Canvas로 제작한 웹앱 결과물을 기록하고 공유합니다.
- 앱별 요구사항, 배포 링크, 회고를 일관된 형식으로 남깁니다.

---
## 1. 유틸리티 앱
## 앱 이름: 영양 성분 분석기

## 카테고리: 유틸리티 앱

### 배포 링크

[https://gemini.google.com/share/56c624d38792](https://gemini.google.com/share/56c624d38792/)

### 이 앱을 만든 이유

- 어떤 문제/불편함을 해결하려고 했나요?
    - 다이어트 혹은 운동을 하면서 먹은 음식의 칼로리나, 단백질 함량을 알기 어렵다는 불편함을 해결하려했습니다.
- 이 앱을 언제, 어떻게 사용할 건가요?
    - 식사를 하기 전에 사진을 찍어서 단백질 함량은 얼마나 되는지 칼로리는 얼마나 되는지 파악하기 위해 사용할 생각입니다.

### 주요 기능

- 실시간 카메라 촬영 기능
- 갤러리 사진 업로드 기능
- AI 기반 음식 사진 분석
- 분석 내용을 바탕으로 음식 이름,  예상되는 칼로리, 단백질, 지방 함량을 출력

### AI 기능 (해당되는 경우)

- 어떤 AI 기능을 추가했나요?
    - 촬영되거나 업로드 된 사진을 바탕으로 AI가 음식을 인식하여 예상되는 칼로리, 단백질, 지방 함량을 출력합니다.
- AI 기능이 앱에서 어떤 역할을 하나요?
    - 음식을 인식하고 예상되는 칼로리, 단백질, 지방 함량을 출력합니다.
    - 음식에 대한 설명을 출력합니다.
